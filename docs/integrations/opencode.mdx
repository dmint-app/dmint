# OpenCode Integration

[OpenCode](https://opencode.ai) supports TypeScript plugins in `.opencode/plugin/` (workspace) and `~/.config/opencode/plugin/` (global) that intercept every tool call via the `tool.execute.before` lifecycle hook.

Dmint generates a zero-dependency OpenCode guard plugin (`dmint-guard.ts`) that evaluates every shell command, file read/write, and MCP tool call against your `policy.json`.

---

## 1. One-Command Setup (`dmint init`)

In your project directory, run:

```bash
# Install in current project (.opencode/plugin/dmint-guard.ts):
dmint init --harness opencode

# Or install globally (~/.config/opencode/plugin/dmint-guard.ts):
dmint hook install --harness opencode --global
```

What this generates:
- `policy.json` — Starter `shell` and `filesystem` policy rules.
- `.dmint/signing.key`, `.dmint/integrity.key`, and `.dmint/approvals.sqlite3`.
- `.opencode/plugin/dmint-guard.ts` — The OpenCode `tool.execute.before` plugin.

---

## 2. How the OpenCode Plugin Works

Whenever OpenCode prepares to execute a tool (`bash`, `read_file`, `write_file`, `edit`, `glob`, `grep`, or an MCP tool), `.opencode/plugin/dmint-guard.ts` invokes `dmint hook run --harness opencode` synchronously over `stdin`:

```typescript title=".opencode/plugin/dmint-guard.ts"
import { spawnSync } from "node:child_process";

export const DmintGuardPlugin = async (_ctx: any) => {
  return {
    "tool.execute.before": async (input: any, output: any) => {
      const payload = JSON.stringify({
        tool_name: input?.tool ?? "",
        session_id: input?.sessionID ?? "opencode-session",
        call_id: input?.callID ?? "",
        tool_input: output?.args ?? {},
      });
      const res = spawnSync(
        "dmint",
        ["hook", "run", "--harness", "opencode", "--policy", "policy.json"],
        { input: payload, encoding: "utf-8" }
      );
      if (res.status !== 0) {
        let reason = (res.stderr || res.stdout || "Blocked by Dmint policy").trim();
        try {
          const parsed = JSON.parse(res.stdout);
          if (parsed && parsed.reason) reason = parsed.reason;
        } catch {}
        throw new Error(reason);
      }
    },
  };
};
```

- **`ALLOW` (Exit `0`)**: The hook returns cleanly and OpenCode runs the tool immediately.
- **`DENY` (Exit `2`)**: The plugin throws an `Error` with the exact Dmint policy code (`DMT_POLICY_DENIED` or `DMT_DEFAULT_DENIED`), halting execution before the tool runs.
- **`APPROVAL_REQUIRED` (Exit `2` until approved)**: The plugin halts the tool and displays the approval ID (`apr_...`) and `dmint approve <id>` command directly in OpenCode.

---

## 3. Approving & Retrying in OpenCode

1. When OpenCode pauses on an `approval_required` action (e.g., modifying `src/index.ts` or running `docker build`), run in your terminal:
   ```bash
   dmint pending
   dmint approve apr_... --by dev@company.com
   ```
2. Ask OpenCode to retry the tool call. `dmint hook run` automatically verifies the Ed25519 signature for the matching RFC 8785 fingerprint, consumes the approval (`APPROVED -> CONSUMED`), and allows the tool to run once.
