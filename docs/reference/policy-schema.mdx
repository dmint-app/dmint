# Policy Schema Specification

This document provides the formal specification for policy definitions evaluated by Dmint Core and generated by the `dmint` CLI (`dmint create-policy` / `dmint create-mcp-policy`).

---

## Core Runtime Policy Mapping

Dmint Core's runtime engine evaluates deterministic policy mappings loaded via `Policy.from_mapping()`.

The direct runtime schema requires `{"rules": [...]}`:

```json title="policy.json"
{
  "rules": [
    {
      "effect": "allow",
      "tool": "postgres",
      "action": "query",
      "resource": "*"
    },
    {
      "effect": "approval_required",
      "tool": "postgres",
      "action": "update",
      "resource": "*"
    },
    {
      "effect": "deny",
      "tool": "postgres",
      "action": "drop",
      "resource": "*"
    }
  ]
}
```

<Warning>
**Core Runtime Strictness**: Dmint Core strictly rejects unknown top-level keys (`PolicyError: unknown policy field`). Do **not** include metadata fields such as `$schema`, `name`, `description`, or `policy_version` in the dictionary passed to `Policy.from_mapping()`. If your deployment stores human metadata in policy files, that metadata must be stripped or extracted before passing the object into `Policy.from_mapping()`.
</Warning>

---

## Top-Level Fields

| Field | Type | Required | Description |
|---|---|---|---|
| `rules` | array | **Yes** | Non-empty array of rule objects evaluated sequentially using fail-closed semantics. |

---

## Rule Object Fields

Each element in the `rules` array defines an authorization rule for an agent action:

| Field | Type | Required | Description |
|---|---|---|---|
| `effect` | string | **Yes** | Decision effect: `"allow"`, `"deny"`, or `"approval_required"`. |
| `tool` | string | **Yes** | Tool identifier or namespace (e.g. `"postgres"`, `"filesystem"`, `"ledger"`). |
| `action` | string | **Yes** | Specific action or method name (e.g. `"query"`, `"transfer"`, `"read"`). |
| `resource` | string | No | Targeted resource string or wildcard (`"*"`). Defaults to matching requests with no resource concept if omitted. |
| `agent_id` | string | No | Optional agent identifier to restrict this rule to a specific agent identity. |
| `conditions` | array | No | Optional trusted context conditions evaluated against environmental attributes. |

---

## Resource Matching Semantics

- **Wildcard (`"resource": "*"`)**: Matches any resource specified in the tool request.
- **Specific String (`"resource": "orders_table"`)**: Matches only requests targeting that exact resource.
- **Omission**: Omitting `"resource"` means the rule *only* matches requests that have no resource concept at all. It does **not** mean "any resource".

---

## RFC 8785 Numeric Canonicalization

<Note>
**Strict Numeric Representation**: Dmint uses deterministic RFC 8785 JSON canonicalization to compute cryptographic request fingerprints. Floating-point numbers that have an integer value (such as `5000.0` or `-0.0`) are strictly rejected with a `CanonicalizationError`. Numerical values representing whole integers must be passed as `int` (`5000`).
</Note>

## JSON Schema (Core Runtime)

```json title="dmint-policy.schema.json"
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "DmintPolicy",
  "type": "object",
  "required": ["rules"],
  "additionalProperties": false,
  "properties": {
    "rules": {
      "type": "array",
      "minItems": 1,
      "items": {
        "type": "object",
        "required": ["effect", "tool", "action"],
        "additionalProperties": false,
        "properties": {
          "effect": {
            "type": "string",
            "enum": ["allow", "deny", "approval_required"]
          },
          "tool": {
            "type": "string",
            "minLength": 1
          },
          "action": {
            "type": "string",
            "minLength": 1
          },
          "resource": {
            "type": "string"
          },
          "agent_id": {
            "type": "string"
          },
          "conditions": {
            "type": "array",
            "items": {
              "type": "object",
              "required": ["field", "operator", "value"],
              "additionalProperties": false,
              "properties": {
                "field": { "type": "string" },
                "operator": {
                  "type": "string",
                  "enum": ["equals", "notEquals", "in", "contains", "startsWith", "endsWith"]
                },
                "value": {}
              }
            }
          }
        }
      }
    }
  }
}
```
