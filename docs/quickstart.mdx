# 5-Minute Quickstart

This walkthrough creates a protected ledger, blocks a denied action, pauses a sensitive transfer for human approval, and retries it with a single-use Ed25519 credential.

---

## Prerequisites

- **Python**: 3.10, 3.11, 3.12, or 3.13.
- **Operating system**: Linux, macOS, or Windows WSL.
- **Dmint**: installed in a clean virtual environment.

---

## Step 1: Install and Initialize

```bash
mkdir dmint-quickstart && cd dmint-quickstart
python3 -m venv .venv
source .venv/bin/activate
pip install dmint
dmint --version
```

```text
dmint 2.0.2
```

Generate the signing and storage-integrity keys:

```bash
dmint init-keys
```

Actual default locations:

```text
~/.config/dmint/signing.key
~/.config/dmint/integrity.key
```

The command prints a `public_key_hex` value. Copy it for the verifier below. The private key stays with the approval process; do not ship it to the agent.

---

## Step 2: Create a Policy

Create `policy.json`:

```json title="policy.json"
{
  "rules": [
    {
      "effect": "allow",
      "tool": "ledger",
      "action": "view_balance"
    },
    {
      "effect": "approval_required",
      "tool": "ledger",
      "action": "transfer_funds"
    },
    {
      "effect": "deny",
      "tool": "ledger",
      "action": "delete_account"
    }
  ]
}
```

Validate and inspect it:

```bash
dmint verify-policy policy.json
```

```text
✓ Verified policy.json: 3 rule(s)
  [ALLOW] tool='ledger', action='view_balance', resource='NoResource'
  [APPROVAL_REQUIRED] tool='ledger', action='transfer_funds', resource='NoResource'
  [DENY] tool='ledger', action='delete_account', resource='NoResource'
```

Rules with no `resource` match only requests with no resource. A global rule would use `"resource": "*"`.

Precedence is fixed: **DENY > APPROVAL_REQUIRED > ALLOW**, regardless of JSON order. A request that matches no rule is denied with `DMT_DEFAULT_DENIED`.

---

## Step 3: Protect the Functions

Create `app.py`:

```python title="app.py"
from datetime import datetime, timedelta, timezone
from pathlib import Path
import sys

from dmint import (
    ApprovalRequiredError,
    ApprovalVerifier,
    AuthorizationError,
    Dmint,
    Policy,
    PolicyProvenance,
    SQLiteApprovalStore,
    TrustedContext,
    policy_digest,
)
from dmint.core import public_key_from_hex

PUBLIC_KEY_HEX = "PASTE_PUBLIC_KEY_HEX"

policy = Policy.from_file("policy.json")
store = SQLiteApprovalStore("approvals.sqlite3", deployment_epoch="default")

dmint = Dmint(
    policy=policy,
    agent_id="finance-agent-01",
    context=TrustedContext({"tenant": "prod-us"}),
    approval_store=store,
    approval_verifier=ApprovalVerifier(
        trusted_issuers={
            "dmint-authority": public_key_from_hex(PUBLIC_KEY_HEX),
        },
        audience="dmint/dashboard/v1",
    ),
    policy_provenance=PolicyProvenance(
        "quickstart-v1",
        policy_digest(policy),
        datetime.now(timezone.utc),
    ),
    approval_ttl=timedelta(minutes=5),
)

@dmint.protect("ledger.view_balance")
def view_balance(account_id: str) -> str:
    return f"Balance for {account_id}: $1,250.00"

@dmint.protect("ledger.transfer_funds")
def transfer_funds(account_id: str, amount: float) -> str:
    return f"Transferred ${amount:.2f} from {account_id}"

@dmint.protect("ledger.delete_account")
def delete_account(account_id: str) -> str:
    return f"Account {account_id} deleted"

if __name__ == "__main__":
    if len(sys.argv) == 2:
        credential = Path(sys.argv[1]).read_bytes()
        print(
            dmint.retry(
                transfer_funds,
                "acc_100",
                500.0,
                approval_credential=credential,
            )
        )
    else:
        print(view_balance("acc_100"))
        try:
            delete_account("acc_100")
        except AuthorizationError as exc:
            print(f"Blocked: {exc.code}")
        try:
            transfer_funds("acc_100", 500.0)
        except ApprovalRequiredError as exc:
            print(f"Paused: {exc.code}")
            print(f"Approval ID: {exc.approval_id}")
            print(f"Request Fingerprint: {exc.request_fingerprint}")
```

Run it:

```bash
python app.py
```

```text
Balance for acc_100: $1,250.00
Blocked: DMT_POLICY_DENIED
Paused: DMT_APPROVAL_REQUIRED
Approval ID: apr_...
Request Fingerprint: 4fb78bc8...
```

The transfer did not execute. Dmint persisted a `PENDING` approval bound to the exact request and raised `ApprovalRequiredError`.

`deny` produces `DMT_POLICY_DENIED`; an unmatched request produces `DMT_DEFAULT_DENIED`. `DMT_AUTHORIZATION_ERROR` is reserved for evaluator/config failures, not an ordinary policy deny.

## Step 4: Approve and Receive the Assertion

List pending requests:

```bash
dmint pending --db-path approvals.sqlite3
```

```text
APPROVAL ID       TOOL/ACTION            RESOURCE/TARGET  PRINCIPAL         REQUESTED
----------------  ---------------------  ---------------  ----------------  ---------
apr_...           ledger.transfer_funds  (none)           finance-agent-01  0s ago
```

Approve the exact request and write the retry credential:

```bash
dmint approve apr_... \
  --db-path approvals.sqlite3 \
  --policy policy.json \
  --approver-id alice@example.com \
  --authority-issuer dmint-authority \
  --reason "Verified quarterly audit transfer" \
  --output-assertion approval.json
```

```text
✓ Approved 'apr_...' (ledger.transfer_funds) successfully.
  Reason: Verified quarterly audit transfer
```

The command updates the record to `APPROVED` and writes signed assertion bytes to `approval.json`. It does not execute the transfer.

> `--authority-issuer` must match the issuer ID in the verifier’s `trusted_issuers` mapping. This example uses `dmint-authority`; `dmint approve` otherwise defaults to `dmint-cli`.

---

## Step 5: Retry Exactly Once

```bash
python app.py approval.json
```

```text
Transferred $500.00 from acc_100
```

Dmint verifies the signature, re-checks the current policy, matches the full request fingerprint, atomically consumes the approval, and only then runs the function.

Replay the same file:

```bash
python app.py approval.json
```

It fails closed with `ApprovalConsumedError` (`DMT_APPROVAL_CONSUMED`). Changing an argument fails with `DMT_APPROVAL_REQUEST_MISMATCH`.
